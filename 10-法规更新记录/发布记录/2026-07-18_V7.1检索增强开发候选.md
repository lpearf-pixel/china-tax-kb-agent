# 2026-07-18 V7.1 检索增强开发候选

## 本候选包含

- main、eligibility、limitation、exclusion、version、local 查询拆解；
- 日期、地域、税种、效力和A级证据硬门禁；
- BM25 与本地512维哈希向量召回；
- 税务百分比和起征点同义规范化；
- Reciprocal Rank Fusion；
- 一跳法规关系扩展；
- 支持、限制、排除、历史、地方和冲突证据分组；
- 当前与历史法规版本隔离；
- 条款级确定性重排序及评分构成；
- 外部 embedding provider 脱敏、失败回退和审计；
- V6/V7旧检索接口兼容；
- 持久案件 `retrieval-vNNN.json`；
- 浏览器和 Obsidian 检索审计展示；
- 30个可执行检索回归用例。

## 安全修复

- 关系扩展候选必须重新通过A级和元数据门禁；
- 外部 provider 不接收完整业务描述；
- provider 失败自动回退本地哈希向量；
- “除……之外”识别为排除证据；
- 同一法规版本内支持片段和排除片段分别保留；
- 历史查询单独加载已废止档案，且不混入当前支持结论；
- 没有 support 证据时旧接口返回空并触发失败关闭。

## 已知边界

- 新疆当前种子库缺少可直接作为A级证据的地方增值税文件；系统生成local查询但不使用B级转载冒充A级依据；
- 本地哈希向量用于召回增强，不等同于专业中文法律 embedding；
- 海南完整进口税则、商品归类和多税种计算不在V7.1范围；
- GitHub Actions Runner 仍存在零步骤启动失败。

## 发布门禁

- 本候选为基于 V7.0 的堆叠 Draft PR；
- V7.0 未合并前，不直接合并本分支到 main；
- 合并前需从远程分支完整检出后再次运行 V5/V6/V7/V7.1 全部测试；
- 不绕过 GitHub Actions 或人工代码审查。
