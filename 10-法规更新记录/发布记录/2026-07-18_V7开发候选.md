# 2026-07-18 V7 税务决策核心开发候选

## 本候选包含

- 事实图谱和事实版本；
- 安全规则 DSL；
- 全国、新疆、海南增值税种子规则；
- 确定性规则引擎；
- Decimal 增值税计算和现金流；
- 税务议题树；
- 动态方案和透明评分；
- 案件状态机、checkpoint 和局部重算；
- 法规变化影响历史案件；
- V6 工作台兼容适配；
- 持久案件 API 和 Obsidian 审计报告；
- 20 个可执行 V7 决策回归用例。

## 发布前自审修复

- 无状态分析不再暴露临时案件编号；
- 关联分拆、交易类型、跨境和海南资格变化会重跑正确节点；
- 网页数字字符串在进入规则前转换为 `Decimal`；
- 规则引擎也能安全比较合法数字字符串；
- 目标日期没有有效规则集时停止税额计算并强制人工复核；
- 没有 A 级法规证据时禁止输出确定结论。
