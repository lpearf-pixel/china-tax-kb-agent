# 税务规划交互工作台

## 启动

在仓库根目录运行：

```bash
python3 -m apps.tax_workbench.server --open
```

默认只监听 `127.0.0.1:8765`，不会暴露到局域网或公网。

## 能力

- 结构化收集业务日期、地区、主体、增值税身份、金额、发票需求和风险事项；
- 检索目标日期有效的 A 级法规与条款；
- 新疆使用全国 + 新疆覆盖层；
- 海南区分普通境内业务和自贸港特殊政策；
- 生成合规基线、发票申报协同、主体身份评估等方案；
- 高风险事项自动要求人工审签；
- 保存为 `16-交互工作台/会话记录/*.md`。

## 当前边界

第一阶段仅围绕增值税、小规模纳税人、新疆和海南。方案为离线、可复现的规则草案，不接外部大模型，不替代专业税务意见。
