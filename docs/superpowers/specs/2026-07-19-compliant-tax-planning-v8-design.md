# 中国税务知识库 Agent V8 合规税务筹划设计

## 1. 定位

V8 将用户口语中的“合理避税”统一定义为：

> 在真实交易、真实商业目的、真实人员资产和完整证据链基础上，依法选择税负、纳税时间、现金流和合规成本更优的业务路径。

系统正式用语为“合规税务筹划”“合法降负”或“税务方案优化”，不输出逃税、骗税、虚假避税或滥用税收优惠方案。

## 2. 绝对禁止范围

以下路径不得进入可选方案，只能返回禁止原因和整改建议：

- 隐匿收入、账外收款、两套账；
- 虚开发票、买票、票货或票款不一致；
- 虚假合同、倒签合同、伪造业务资料；
- 无真实业务的关联交易和资金空转；
- 为适用起征点或小规模政策而人为分拆主体、合同或销售额；
- 只有注册地、没有人员资产和实际经营的空壳迁移；
- 将劳动关系虚构为外包、劳务或个体经营；
- 关联定价明显不符合独立交易原则；
- 通过个人账户收取企业经营收入；
- 违反一般反避税、特别纳税调整、受益所有人或实质重于形式原则的安排。

## 3. 目标

V8 应能：

1. 先计算“不改变业务结构”的合规基线；
2. 只从允许的决策变量中生成候选方案；
3. 对每个方案核验商业目的、经济实质和资料可得性；
4. 计算增值税、企业所得税、个人所得税及后续税种的分项税负；
5. 比较当前税负、未来税负、纳税时点、现金流、实施成本和风险；
6. 明确哪些差异来自优惠、递延、交易路径或资料完善；
7. 对高风险安排强制人工审签；
8. 在法规变化后自动重新评估历史方案。

## 4. 核心架构

```text
确认后的事实图谱
→ 合规基线方案
→ 税务机会识别
→ 允许的决策变量
→ 候选业务路径
→ 商业目的和经济实质校验
→ 反避税与禁止模式门禁
→ 分税种规则和计算
→ 税负、现金流、成本和风险评分
→ 证据与实施资料包
→ 人工审签
→ 持续监控和法规变更重算
```

LLM 只能用于业务访谈、事实候选抽取和结果解释。方案是否合法、优惠是否适用、税额是多少，仍由确定性规则、计算器和人工审签决定。

## 5. 新增领域模型

### PlanningObjective

- 降低确定性税负；
- 延缓纳税时间；
- 改善现金流；
- 降低稽查和申报风险；
- 降低发票或交易摩擦；
- 提高政策资格确定性。

### DecisionVariable

只允许修改不改变事实真实性的变量，例如：

- 合法主体形式；
- 纳税人登记身份；
- 合同价税条款；
- 付款和交付时点；
- 发票类型和开票时点；
- 股权融资或债权融资；
- 资产购买或股权购买；
- 工资、奖金、分红等真实报酬路径；
- 符合资格的区域和产业政策申请；
- 会计资料、台账和证明文件完善。

### BusinessPurposeAssessment

记录：

- 非税商业目的；
- 业务必要性；
- 人员、资产、场所和职能；
- 决策和风险承担；
- 合同、资金、发票、货物或服务是否一致；
- 不采用该路径时的商业后果。

### SubstanceAssessment

输出 `sufficient / insufficient / uncertain`，并列出人员、资产、办公场所、业务系统、决策权、成本承担和收入来源等证据缺口。

### PlanningScenario

在现有 `Scenario` 上增加：

- `planning_type`；
- `decision_variables`；
- `business_purpose`；
- `substance_status`；
- `anti_abuse_flags`；
- `tax_savings`；
- `tax_deferral`；
- `implementation_cost`；
- `evidence_requirements`；
- `reversal_risk`；
- `prohibited_reason`。

## 6. 方案评分

不以“税额最低”作为唯一目标。推荐权重：

```text
法律确定性              25%
经济实质和商业目的      20%
税负改善                15%
现金流和递延价值        10%
资料完整度              10%
实施成本                10%
持续维护成本             5%
被否定后的补税风险       5%
```

出现禁止模式、缺少真实商业目的或实质不足时，方案直接淘汰，不参与排序。

## 7. 阶段划分

### V8.0 合规筹划核心

- 基线与候选方案模型；
- 决策变量白名单；
- 禁止模式和反避税门禁；
- 商业目的、经济实质和证据评分；
- 税负节省与递延价值拆分；
- 方案差异审计。

### V8.1 主体和纳税身份

- 公司、个体工商户、个人独资和合伙企业的适用边界；
- 小规模与一般纳税人登记；
- 真实多主体经营和禁止人为分拆；
- 总分机构与汇总纳税资格。

### V8.2 合同、发票和交易时点

- 含税与不含税报价；
- 发票类型与客户抵扣需求；
- 纳税义务发生时间；
- 预收款、分期付款和履约里程碑；
- 合同流、发票流、资金流、货物流或服务流一致性。

### V8.3 用工和报酬

- 工资薪金、全年一次性奖金、劳务报酬、经营所得和分红的真实分类；
- 雇佣与独立劳务边界；
- 股权激励和长期激励仅做资格预审；
- 禁止将劳动关系虚构为个体经营。

### V8.4 投资和融资

- 股权与债权融资；
- 利息扣除、资本弱化和关联融资门禁；
- 分红、增资、减资和股权转让；
- 境外投资和协定事项强制人工复核。

### V8.5 资产、股权和重组

- 资产购买与股权购买；
- 设备租赁与购买；
- 作价投资、划转、合并和分立；
- 房地产、土地增值税和契税联动；
- 所有重组方案强制专业审签。

### V8.6 区域和产业优惠

- 海南、新疆及后续地区政策；
- 小型微利、高新技术、研发加计扣除和加速折旧；
- 产业目录、人员资产和实质运营门禁；
- 优惠到期和追溯调整风险。

### V8.7 持续合规

- 月度或季度方案实际执行对比；
- 资格条件漂移预警；
- 法规变化后自动重算；
- 方案实施证据包和年度复核。

## 8. 输出格式

每个方案必须包含：

- 业务路径说明；
- 与基线相比改变了什么；
- 法规依据和有效期；
- 税种分项和综合税负；
- 税负节省与递延价值分别列示；
- 商业目的和经济实质；
- 所需合同、发票、台账和审批；
- 实施步骤；
- 禁止边界；
- 风险等级和人工审签要求；
- 法规变化后的重算触发条件。

## 9. 验收标准

V8.0 完成时，同一真实业务修改允许的决策变量后，系统应能：

- 生成合规基线和至少两个合法候选方案；
- 淘汰虚假分拆、空壳迁移等禁止方案；
- 区分永久节税和仅递延纳税；
- 展示分税种税额、现金流和实施成本；
- 每个结论回链事实、规则、法规、公式和证据；
- 缺少商业目的、经济实质或 A 级证据时失败关闭；
- 法规更新后标记受影响方案并重新评估。
