# V7.2.1 个人所得税基础 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 增加经营所得年度计算、个体工商户减半优惠和居民个人劳务报酬预扣，并与现有多税种方案聚合。

**Architecture:** 个人所得税采用独立法源、事实、议题、规则和计算器。规则确定所得分类和适用路径，阶梯税率计算器负责确定性税额，多税种聚合器保持不同纳税主体和税种不相互抵减。
