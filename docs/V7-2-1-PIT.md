# V7.2.1 个人所得税基础指南

V7.2.1 在 V7.2 企业所得税多税种基础上加入个人所得税第一批确定性能力：经营所得年度计算、个体工商户阶段性减半优惠，以及居民个人劳务报酬预扣预缴。

## 当前支持

### 经营所得

- 居民个人经营所得；
- 个体工商户业主；
- 个人独资企业投资者；
- 已确认分配所得的合伙企业自然人合伙人；
- 年度 5%—35% 五级超额累进税率；
- 其他个人所得税减免和已预缴税额；
- 多处经营所得合并门禁；
- 个体工商户 2023—2027 年不超过 200 万元部分减半优惠。

### 劳务报酬

- 居民个人独立劳务报酬；
- 每次收入不超过 4000 元时减除 800 元；
- 每次收入超过 4000 元时减除 20%；
- 20%、30%、40% 三级预扣率；
- 已预扣税额和当前补扣候选；
- 明确标记居民个人年度综合所得汇算。

## 不自动计算

以下事项仅路由和人工复核：

- 非居民个人；
- 境外所得和税收协定；
- 合伙企业分配所得未确认；
- 多处经营所得未合并；
- 工资薪金累计预扣；
- 居民个人完整综合所得年度汇算；
- 稿酬和特许权使用费；
- 财产租赁、财产转让、利息股息红利和偶然所得；
- 核定征收和定期定额税额。

## 经营所得税率

| 全年应纳税所得额 | 税率 | 速算扣除数 |
|---|---:|---:|
| 不超过 30,000 元 | 5% | 0 |
| 30,000—90,000 元 | 10% | 1,500 |
| 90,000—300,000 元 | 20% | 10,500 |
| 300,000—500,000 元 | 30% | 40,500 |
| 超过 500,000 元 | 35% | 65,500 |

```text
基础税额 = 全年应纳税所得额 × 税率 - 速算扣除数
```

## 个体工商户减半优惠

适用期：2023-01-01 至 2027-12-31。

```text
减免税额
=（不超过200万元部分的应纳税额
  - 其他政策减免税额 × 不超过200万元部分 / 全年应纳税所得额）× 50%
```

系统仅在以下条件满足时自动计算：

- 纳税人角色为个体工商户业主；
- 业务日期处于优惠有效期；
- 多处经营所得已合并；
- 全年应纳税所得额、其他减免和预缴税额已确认。

个人独资企业投资者和合伙企业自然人合伙人不套用该减半优惠。

## 劳务报酬预扣

```text
收入不超过4000元：预扣所得额 = 收入 - 800元
收入超过4000元：预扣所得额 = 收入 × 80%
```

| 预扣应纳税所得额 | 预扣率 | 速算扣除数 |
|---|---:|---:|
| 不超过 20,000 元 | 20% | 0 |
| 20,000—50,000 元 | 30% | 2,000 |
| 超过 50,000 元 | 40% | 7,000 |

```text
预扣税额 = 预扣应纳税所得额 × 预扣率 - 速算扣除数
```

居民个人劳务报酬在年度终了后并入综合所得汇算。V7.2.1 展示的是当前预扣候选，不是最终年度税负。

## 启动工作台

```bash
python3 -m apps.tax_workbench.server --open
```

浏览器选择“个人所得税”，再选择：

- 所得类别：经营所得或劳务报酬；
- 居民身份；
- 纳税人角色；
- 对应收入、所得、减免、预缴或预扣事实。

## 多税种聚合

V7.2.1 支持：

- PIT-only；
- VAT + PIT；
- CIT + PIT；
- VAT + CIT + PIT。

每个方案分别保存：

```json
{
  "tax_breakdown": {
    "增值税": "4000.00",
    "企业所得税": "50000.00",
    "个人所得税": "1600.00"
  }
}
```

不同税种和不同纳税主体之间不直接抵减。劳务报酬预扣税额需要结合年度汇算单独解释。
