# V8 合规税务筹划项目

## 正式定位

项目不使用“逃税”或“隐匿税负”作为目标。用户口语中的“合理避税”统一解释为：

> 在真实业务、真实商业目的、经济实质和完整证据链基础上，依法选择更适合的主体、合同、发票、用工、投融资、资产和优惠路径。

## 八类后续项目

1. **主体与纳税身份**：公司、个体工商户、个人独资、合伙企业，小规模与一般纳税人；
2. **合同与发票**：价税条款、发票类型、付款和履约时点；
3. **用工与报酬**：工资、奖金、劳务、经营所得、分红和股权激励边界；
4. **投资与融资**：股权、债权、利息、分红、增资、减资和股权转让；
5. **资产与股权交易**：资产购买、股权购买、租赁与购买；
6. **企业重组**：作价投资、划转、合并、分立和清算；
7. **区域与产业优惠**：海南、新疆、高新技术、研发加计扣除和加速折旧；
8. **持续合规**：执行监控、资格漂移、法规变化重算和年度复核。

## 先决门禁

候选方案必须全部满足：

- 有非税商业目的；
- 有真实人员、资产、场所、职能和风险承担；
- 合同、发票、资金、货物或服务流一致；
- 有目标日期有效的 A 级法规证据；
- 有完整实施和留档资料；
- 不触发禁止模式。

## 禁止模式

- 隐匿收入、账外资金和两套账；
- 虚开发票或票货、票款不一致；
- 虚假合同、倒签资料和伪造证据；
- 人为分拆主体、销售额或合同；
- 无实质运营的空壳迁移；
- 虚构劳务、外包或个体经营关系；
- 关联资金空转和不符合独立交易原则的定价；
- 个人账户收取企业经营收入。

禁止方案只输出拒绝原因、风险和整改建议，不进入税额比较和排序。
