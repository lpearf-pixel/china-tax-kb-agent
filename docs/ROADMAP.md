# 项目路线图

## V5：法规知识库基线

已冻结范围：

- 全国 2026 年增值税规则底座；
- 小规模纳税人、自然人和个体工商户；
- 新疆维吾尔自治区覆盖层；
- 海南自由贸易港覆盖层；
- 条款级检索、时间过滤、地域过滤；
- 法规效力关系、人工审签和回归测试。

## V5.x：法规内容持续建设

- 完成官方来源联网指纹基线；
- 增加新增、修改、废止和延期分类；
- 精编新疆地方执行资料；
- 精编海南封关后“一线、二线、岛内流通”资料；
- 扩充农产品、房地产、资源和高频办税场景。

## V7.1：检索增强

- BM25 + 本地向量混合召回；
- 查询拆解与税务议题驱动检索；
- 条款重排序；
- 支持证据、限制证据、排除证据和失效证据分组；
- 法规版本序列和双时间检索；
- 独立评价检索器、规则判断和最终答案。

## V7.2：多税种联动

按风险和依赖顺序增加：

1. 企业所得税；
2. 个人所得税；
3. 印花税；
4. 契税；
5. 土地增值税；
6. 海南进口、关税和消费税完整计算。

## V7.3：受限智能交互

- LLM 业务访谈和事实候选抽取；
- 合同、发票和财务资料的本地解析；
- 用户确认后写入事实图谱；
- LLM 只解释确定性结果，不改变规则和税额；
- 团队权限、审签角色和敏感数据加密。

## 长期目标

- Obsidian 保持人工知识事实源；
- Workflow 管住高风险流程；
- RAG 约束 LLM 只能使用有效证据；
- 规则引擎承担政策适用判断；
- 计算引擎承担税额和现金流计算；
- 所有正式结果可追溯到事实版本、法规条款、规则版本、计算公式和审签记录。
