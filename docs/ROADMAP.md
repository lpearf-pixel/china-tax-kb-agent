## V8：合规税务筹划

正式名称为“合规税务筹划”或“合法降负”。虚假交易、虚开发票、隐匿收入、两套账、空壳迁移、人为分拆和虚构劳务等路径不得进入候选方案。

### V8.0 合规筹划核心

- [ ] 合规基线和候选方案模型；
- [ ] 决策变量白名单；
- [ ] 商业目的评估；
- [ ] 经济实质评估；
- [ ] 禁止模式和反避税门禁；
- [ ] 税负节省与纳税递延分开计算；
- [ ] 实施成本、证据完整度和被否定风险评分；
- [ ] 法规变化后的方案重算。

## V9：受限智能交互

- LLM 业务访谈和事实候选抽取；
- 合同、发票和财务资料的本地解析；
- 用户确认后写入事实图谱；
- LLM 只解释确定性结果，不改变规则和税额；
- 团队权限、审签角色和敏感数据加密。

## 长期目标

- Obsidian 保持人工知识事实源；
- Workflow 管住高风险流程；
- RAG 约束 LLM 只能使用有效证据；
- 分税种规则引擎承担政策适用判断；
- 分税种计算引擎承担税额和现金流计算；
- 合规筹划引擎只生成真实、有商业目的和经济实质的合法路径；
- 所有正式结果可追溯到事实版本、法规条款、检索轨迹、规则版本、计算公式和审签记录。
