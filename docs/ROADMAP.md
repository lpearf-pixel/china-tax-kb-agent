# 项目路线图

## V5 第一阶段：增值税试点

范围已经冻结为：

- 全国 2026 年增值税规则底座；
- 小规模纳税人、自然人和个体工商户；
- 新疆维吾尔自治区覆盖层；
- 海南自由贸易港覆盖层；
- 条款级检索、时间过滤、地域过滤；
- 法规效力关系、人工审签和回归测试。

## V5.1：法规更新可靠性

- 完成官方来源首次联网指纹基线；
- 增加新增、修改、废止和延期分类；
- 更新影响报告关联到条款、场景和案例；
- 建立高影响法规人工审核清单。

## V5.2：新疆与海南精编

- 新疆增值税地方执行资料；
- 新疆农产品、房地产和资源相关高频场景；
- 海南封关后“一线、二线、岛内流通”场景；
- 海南享惠主体、商品编码和用途流向门禁；
- 地方口径与全国上位法冲突测试。

## V6：扩展税种

通过增值税试点评测后，依次增加：

1. 企业所得税；
2. 个人所得税；
3. 契税与土地增值税；
4. 印花税；
5. 房产税、城镇土地使用税和资源税费。

## 长期目标

- Obsidian 保持唯一人工维护事实源；
- Workflow 管住高风险流程；
- RAG 约束 LLM 只能基于有效证据回答；
- 所有正式答案可追溯到法规、条款、业务日期和知识库版本。
