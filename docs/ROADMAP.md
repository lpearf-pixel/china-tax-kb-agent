- 合同、发票和财务资料的本地解析；

## 长期目标

- Obsidian 保持人工知识事实源；
- Workflow 管住高风险流程；
- RAG 约束 LLM 只能使用有效证据；
- 分税种规则引擎承担政策适用判断；
- 分税种计算引擎承担税额和现金流计算；
- 所有正式结果可追溯到事实版本、法规条款、检索轨迹、规则版本、计算公式和审签记录。
