# V8 合规税务筹划 Epic

## 目标

在三税种确定性计算基础上，生成具有真实商业目的、经济实质和完整证据链的合法筹划方案。

## 零容忍门禁

以下方案不得进入税额比较和排序：隐匿收入、虚开发票、虚假合同、空壳迁移、人为分拆、虚构用工或劳务、关联资金空转、个人账户收取企业经营收入。
