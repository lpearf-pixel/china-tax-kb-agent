# 本地工具入口


在 `90-工具` 目录运行：

- `python3 taxkb_validate.py`：校验元数据、官方来源和链接；
- `python3 taxkb_export.py --profile full`：导出 JSONL 分块；
- `python3 taxkb_query.py "问题" --jurisdiction CN-XJ --valid-on 2026-07-17`：新疆检索；
- `python3 taxkb_query.py "问题" --jurisdiction CN-HI --valid-on 2026-07-17`：海南检索；
- `python3 taxkb_eval.py`：回归评测；
- `python3 taxkb_update.py`：来源变化检查；
- `python3 taxkb_impact.py "法规路径"`：法规变化影响追踪。
