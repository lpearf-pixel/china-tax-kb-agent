# 中国税务知识库 Agent

知识库基线：`KB-2026.07.17-V5-PILOT-XJ-HI`  
当前开发线：`V7.2.1 增值税 + 企业所得税 + 个人所得税`

以 **Obsidian 为人工知识事实源**，采用版本感知混合检索、安全规则 DSL、分税种确定性计算、案件状态机和人工审签，辅助查询、解释、测算和比较中国税务方案。

> 全国规则底座 + 新疆覆盖层 + 海南自贸港覆盖层 + 混合 RAG + 分税种规则引擎 + Decimal 计算 + 合规筹划路线图

## 当前范围

- 增值税：小规模纳税人、自然人、个体工商户及一般纳税人基础测算；
- 企业所得税：居民公司制企业一般计算与 2023—2027 小型微利企业优惠；
- 个人所得税：经营所得五级税率、个体工商户减半优惠、居民个人劳务报酬预扣；
- 地域：全国、新疆和海南；
- 综合输出：增值税、企业所得税、个人所得税分项与综合税负；
- 高风险事项：非居民、跨境、关联、合伙分配、重组、房地产、海南特殊政策、历史补税和稽查强制人工复核。

尚未进入确定性计算的主要范围：工资薪金完整累计预扣、综合所得年度汇算、印花税、契税、土地增值税、关税及企业所得税专项优惠。

## V7.2.1 决策流程

```text
业务事实和所选税种
→ 事实图谱与事实版本
→ 分税种议题树和查询拆解
→ 日期/地域/效力/A级证据门禁
→ BM25 + 本地哈希向量召回
→ 证据角色分类和版本选择
→ 增值税规则与计算
→ 企业所得税规则与计算
→ 个人所得税规则与计算
→ 税种分项和综合税负
→ 动态方案评分
→ 人工审签
→ Obsidian 报告和案件审计
```

正式法规依据只能来自 `01-法规原文` 和 `02-条款结构`。没有目标日期有效的 A 级支持证据或规则集时，系统失败关闭。

## 启动本地工作台

```bash
python3 -m apps.tax_workbench.server --open
```

默认只监听：

```text
http://127.0.0.1:8765
```

工作台支持：

- 选择增值税、企业所得税、个人所得税或其组合；
- 填写会计利润、纳税调整、亏损、预缴和小型微利企业指标；
- 填写经营所得、纳税人角色、劳务报酬和扣缴义务；
- 查看分税种法规证据、规则轨迹和计算公式；
- 查看每个方案的税种分项及综合税负；
- 建立本地持久案件、修订事实、局部重算和人工审签；
- 保存 Obsidian 决策报告和检索审计版本。

真实案件保存在 `cases/`，会话报告保存在 `16-交互工作台/会话记录/`，默认不提交 Git。

## 企业所得税基础公式

```text
应纳税所得额
= 会计利润
+ 纳税调增
- 纳税调减
- 可弥补亏损
```

一般居民企业：

```text
应纳所得税额 = max(应纳税所得额, 0) × 25%
```

2023—2027 年符合条件的小型微利企业：

```text
应纳所得税额 = max(应纳税所得额, 0) × 25% × 20%
```

## 个人所得税第一批能力

经营所得：

```text
基础税额 = 全年经营所得应纳税所得额 × 5%—35%税率 - 速算扣除数
```

符合条件的个体工商户在 2023—2027 年对不超过 200 万元部分减半征收，系统不会将该优惠扩展到个人独资企业或合伙企业。

居民个人劳务报酬当前只计算预扣候选：

```text
预扣应纳税所得额 = 收入 - 800元，或收入 × 80%
预扣税额 = 预扣应纳税所得额 × 20%/30%/40% - 速算扣除数
```

支付方扣缴义务未确认时停止确定性计算。居民个人年度终了后仍需按规定并入综合所得汇算，预扣金额不等于最终年度税负。

负数应补退税额只作为退税或多缴候选，不跨税种抵减。

## V8 合规税务筹划

用户口语中的“合理避税”在项目中统一称为 **合规税务筹划** 或 **合法降负**。

V8 将建设：

- 合规基线与候选方案；
- 决策变量白名单；
- 商业目的和经济实质评估；
- 虚假合同、虚开发票、空壳迁移和人为分拆等禁止模式门禁；
- 主体、合同发票、用工报酬、投融资、资产重组和区域优惠方案库；
- 税负节省、纳税递延、现金流、实施成本和风险评分；
- 法规变化后的方案自动重算。

V8 不生成隐匿收入、两套账、虚构劳务、个人账户收款或其他逃税方案。

```bash
cd 90-工具
python3 taxkb_update.py
```

变化只进入 `10-法规更新记录/待审核/`。确认发布后，系统沿：

```text
provision_id → rule_id → case_id → scenario_id
```

识别受影响案件，保留原事实、规则和计算版本。
